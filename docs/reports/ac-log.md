# Acceptance-criteria log

One row per ticket, added by the feature pipeline (Prompt 5 §8.f, or the FE final report). Per-ticket detail is in `docs/reports/<ID>/ac-results.md`.
Results are PASS, FAIL, N/A or NOT RUN, always from real test output. A ticket is not done while any AC is FAIL or NOT RUN without a written owner decision.
